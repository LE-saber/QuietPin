# 更新日志 / Changelog

## v0.2.0 — 2026-10-05

### 中文

- 可选 Pin 按钮，点击置顶 / 取消，不抢焦点；默认关闭。
- 事件驱动的窗口跟随、安全定位、DIP 位置偏移与重置。
- 排除程序不显示 Pin；兼容 v0.1 配置。
- Windows 11 x64 当前用户安装版及便携 ZIP。
- 安装向导可选 English / 简体中文，默认英语；程序语言可在设置中修改，保留已有选择。
- 升级和卸载仅退出本安装路径的实例，清理本安装的文件、快捷方式与启动项，保留个人设置。
- 设置中手动检查 GitHub 更新，支持同版本发布文件比较；通过下载页面获取更新。

### English

- Optional, default-off Pin button to toggle always-on-top without taking focus.
- Event-driven window tracking, safe placement, DIP offsets and position reset.
- Excluded programs have no Pin button; v0.1 settings remain supported.
- Windows 11 x64 per-user installer and portable ZIP.
- English / Simplified Chinese installation wizard, defaulting to English; application language is configurable and existing choices are preserved.
- Upgrade and uninstall stop only the installed copy, remove its files, shortcuts and startup entry, and preserve personal settings.
- Manual GitHub update checking in Settings, including same-version build comparison; updates are available through the download page.

## v0.1.0 — 2026-10-05

**中文：** 原生 Win32 MVP：无托盘后台运行、全局置顶热键、自定义热键、中英文设置、不抢焦点的状态提示、可选托盘、程序排除、登录启动、单实例及无托盘退出。

**English:** Native Win32 MVP: background operation without a tray icon, global and custom topmost shortcuts, bilingual Settings, nonactivating feedback, optional tray, exclusions, sign-in startup, single-instance management and no-tray exit.

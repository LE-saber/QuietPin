# QuietPin

[English](README.md) · [简体中文](README.zh.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

Windows 11 x64 用の軽量な最前面表示ツールです。C++20 / Win32 で実装され、追加ランタイムを必要としません。既定ではメインウィンドウ、タスクバーのボタン、トレイアイコンを表示せず、バックグラウンドで動作します。

## クイックスタート

| 操作 | 既定のショートカット |
| --- | --- |
| アクティブウィンドウの最前面表示を切り替え | **Ctrl + Alt + T** |
| 設定を開く | **Ctrl + Alt + Shift + T** |
| QuietPin を終了 | **Ctrl + Alt + Shift + Q** |

同じウィンドウでもう一度切り替えると解除します。複数のウィンドウを固定できます。

`QuietPin.exe` をもう一度実行すると、起動済みインスタンスの設定が開きます。パッケージには `open-settings.cmd` と `exit.cmd` も含まれます。設定を閉じると背景動作に戻り、**Exit QuietPin** で完全に終了します。

## 設定

- 最前面表示のショートカットを変更できます。競合する場合は以前の設定を維持します。
- 短い状態通知、サインイン時の起動、トレイアイコン、Pin ボタンを切り替えられます。
- **English** または **中文** を選び **Save** を押します。新規設定は英語で、既存の言語選択は保持します。
- EXE 名または完全なパスを 1 行ずつ指定してアプリを除外できます。除外したアプリには固定操作と Pin ボタンの両方を適用しません。
- Pin の X/Y オフセットを調整、または位置をリセットできます。
- **Check for updates** で手動確認し、**Download page** を開けます。定期的な背景確認や自動インストールはありません。同一バージョン番号でも公開 EXE のハッシュから異なるビルドを識別します。

Pin とトレイは既定で無効です。Pin はアクティブウィンドウのタイトルバー付近を追従し、フォーカスを奪いません。安全な表示位置がない場合は隠れますが、キーボード操作は利用できます。

インストーラーは英語と簡体字中国語に対応し、既定は英語です。アプリの言語は設定で別に選択します。

## インストールと削除

既定の保存先は `%LOCALAPPDATA%\Programs\QuietPin` です。スタートメニューには実行、設定、終了、アンインストールの項目を用意し、デスクトップショートカットは任意です。Windows の「設定 → アプリ → インストールされているアプリ」からも削除できます。

更新とアンインストールは、そのインストール先の実行ファイルにだけ正常終了を要求します。インストールしたファイルとショートカットを削除し、スタートアップ項目は同じインストール先を参照している場合にだけ削除します。個人設定は再導入のために保持します。

インストール版とポータブル版はどちらも `%LOCALAPPDATA%\QuietPin\settings.ini` に設定を保存します。ポータブル版を削除する場合は、サインイン起動を無効にして終了し、フォルダーを削除します。個人設定も削除する場合は、終了後に `%LOCALAPPDATA%\QuietPin` を削除してください。

## 動作範囲

通常のユーザー権限で動作し、権限の高いウィンドウや保護されたウィンドウには案内を表示します。デスクトップ、タスクバー、特殊な Shell ウィンドウは対象外です。最前面表示は通常のウィンドウより上になる指定であり、排他的フルスクリーン、別の最前面ウィンドウ、セキュアデスクトップには覆われる場合があります。

通常終了では、このインスタンスが固定したウィンドウを戻すよう試みます。強制終了や他のツールによる同じウィンドウの変更で復元できない場合は、対象ウィンドウの最前面状態を再度切り替えてください。

## ソースからビルド

Windows、CMake 3.20+、C++20 コンパイラが必要です。パッケージ作成には Inno Setup 6.7+ を使います。

```powershell
.\scripts\build.ps1 -Compiler MinGW -SkipTests
```

または VS 2022 Developer PowerShell と新しいビルドフォルダーで実行します。

```powershell
.\scripts\build.ps1 -Compiler MSVC -SkipTests
.\scripts\package.ps1 -InnoCompiler "C:\Path\ISCC.exe"
```

コマンドライン引数は `--settings`、`--exit`、`--startup`、独立した設定用の `--config-dir "C:\Profile"` です。`--exit-if-owned` はインストーラー内部で使用し、そのインストール先のコピーだけを停止します。

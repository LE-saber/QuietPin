# QuietPin v0.2.0 — Pin 按钮 / Pin button

## 中文

v0.2 新增可选 Pin 按钮，同时提供 Windows 11 x64 安装版和便携 ZIP。原生 C++/Win32，默认后台运行，不显示主窗口、任务栏或托盘图标。

### 更新内容

- Pin 点击置顶/取消，不抢前台和键盘焦点；默认关闭。
- 事件跟随窗口移动、缩放和状态变化，支持 DIP 偏移及恢复默认位置。
- 排除程序不显示 Pin；无安全位置、窄窗或无标题全屏自动隐藏，仍可使用快捷键。
- 中英文设置与 Pin 提示，保留自定义快捷键、状态提示、可选托盘、登录启动和无托盘退出。
- 新增当前用户安装版，无需管理员权限；开始菜单提供运行、设置、退出、卸载。
- 兼容 v0.1 配置；升级默认保持 Pin 关闭。卸载保留配置，仅清理属于本安装路径的启动项。

### 下载与使用

选择 `QuietPinSetup-v0.2.0-win-x64.exe` 安装，或解压 `QuietPin-v0.2.0-win-x64.zip` 后运行 `QuietPin.exe`。`QuietPin-v0.2.0-SHA256SUMS.txt` 提供两个文件的 SHA256。

默认快捷键：置顶 **Ctrl+Alt+T**；设置 **Ctrl+Alt+Shift+T**；退出 **Ctrl+Alt+Shift+Q**。启用 Pin：打开设置，勾选“显示活动窗口 Pin 按钮”，保存。

## English

v0.2 adds an optional Pin button and ships both a Windows 11 x64 installer and a portable ZIP. Native C++/Win32, quiet background operation, with no main window, taskbar button or tray icon by default.

### Changes

- Click Pin to toggle topmost without taking foreground or keyboard focus; disabled by default.
- Event-driven movement/resize/state tracking, DIP offsets and position reset.
- Exclusions hide Pin. Unsafe locations, narrow windows and borderless fullscreen hide it while shortcuts remain available.
- Chinese/English application Settings and Pin feedback; custom shortcuts, status feedback, optional tray, sign-in startup and no-tray exit are retained.
- New per-user installer without administrator rights; Start menu entries for Run, Settings, Exit and Uninstall.
- v0.1 configurations remain compatible and upgrade with Pin off. Uninstall preserves settings and only removes its own installation path's startup entry.

### Download and use

Install `QuietPinSetup-v0.2.0-win-x64.exe`, or extract `QuietPin-v0.2.0-win-x64.zip` and run `QuietPin.exe`. `QuietPin-v0.2.0-SHA256SUMS.txt` contains checksums for both downloads.

Default shortcuts: toggle **Ctrl+Alt+T**, Settings **Ctrl+Alt+Shift+T**, Exit **Ctrl+Alt+Shift+Q**. To enable Pin, open Settings, check **Show Pin near the active window**, then Save. The installer interface is English; the application supports both languages.

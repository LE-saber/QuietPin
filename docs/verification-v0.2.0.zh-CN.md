## 安装与配置

安装版针对 Windows 11 x64，当前用户安装，不要求管理员权限。默认目录 `%LOCALAPPDATA%\Programs\QuietPin`，开始菜单提供运行、设置、退出、卸载，桌面快捷方式可选。安装不自动开启登录启动、托盘或 Pin。升级先等待当前安装路径运行的实例正常退出；其他路径便携实例保留。卸载仅清理指向本安装路径的 QuietPin 登录启动项，保留用户配置，不撤销其他路径启动项。

ZIP 无需安装，解压运行即可；默认设置同样保存在 `%LOCALAPPDATA%\QuietPin`。可用 `--config-dir` 将配置放在自定义目录，注意多个配置实例的全局快捷键仍需避开冲突。

## 已知验证边界

本版为未签名 MinGW 构建。MSVC、真实双屏/热插拔、锁屏/虚拟桌面、管理员目标、各版本浏览器/Electron 自绘标题栏、Explorer 重启、实际登录启动及两小时稳定性仍待手工实测，不宣称所有 Windows 11 应用完整兼容。没有安全位置时 Pin 隐藏，可继续使用全局快捷键。

Pin 的标题内侧位置需通过有界 WM_NCHITTEST 五点 HTCAPTION 验证；不覆盖客户端标签或系统按钮。外侧位置受屏幕工作区和窗口边界限制。静止不默认轮询；移动补偿 33ms，单次最多 5 秒，停用时释放全部 Pin 专属窗口、hook、session notification 和 timer。

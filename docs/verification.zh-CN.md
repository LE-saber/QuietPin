# QuietPin MVP 0.1 验证记录

日期：2026-10-05（北京时间）。本记录针对本地生成的 MinGW x64 MVP；不代表完整五阶段产品已验收。

## 构建环境与产物

- 本机：Windows 11 家庭版 中文版，10.0.26300，16 个逻辑处理器。
- 编译器：MinGW GCC 14.2.0，x86_64 MCF/SEH/UCRT；CMake 4.3.4 + Ninja。
- Release C++20，原生 Windows GUI 子系统，PerMonitorV2 manifest，asInvoker / uiAccess=false。
- EXE 大小：**1,251,840 字节（约 1.194 MiB）**。
- SHA-256：`2fa69c88e27a411a6fffdb01af8c0945d7278b140bba10935d75b6503526a924`。
- 导入表仅含 Windows 自带 DLL：User32、Kernel32、Advapi32、Gdi32、Comctl32、Comdlg32、Dwmapi、Shell32、Ole32、Ntdll 和系统 UCRT API sets。没有 libstdc++ / libgcc / libmcfgthread 外部 DLL，没有 .NET 或浏览器宿主依赖。
- 本包未签名。MSVC 构建路径提供，未实机验证。
- 发布 ZIP 已解压到含中文与空格的目录，并对解压后的 EXE 重新执行完整 Win32 集成测试，通过；包内 EXE 与构建产物 SHA-256 一致。验证结束没有遗留 QuietPin 后台进程。

## 自动测试

`scripts/build.ps1 -Compiler MinGW` 构建成功。最终 `ctest --test-dir build --output-on-failure`：**2/2 测试通过**，本次约 1.29 秒。两个测试内部覆盖多个场景，不将“2 个测试”表述为只有两项检查。

### Core 测试

- 默认与非法快捷键输入、F12 拒绝。
- EXE 文件名与完整路径精确匹配、大小写、中文与空格路径、不采用子串匹配。
- UTF-16LE 配置往返、原子替换、非法换行注入拒绝、失败后保留旧配置。
- 损坏配置读取不会改变已接受的内存设置。
- 桌面保护、自身窗口拒绝、销毁后的身份失效和操作拒绝。
- 使用带 PID 的独立测试启动项验证写入、引用当前 EXE 的双引号命令、删除自己的值、拒绝修改其他路径的值；结束恢复测试前快照。不触碰正式 QuietPin 启动项。

### Win32 集成测试

创建受控测试窗口并启动独立配置的真正 QuietPin.exe。测试使用自己的窗口，不对用户正在工作的窗口做置顶操作。测试结束尽力恢复原前台。

- 普通启动隐藏宿主且不自动显示设置。
- 真实 SendInput 全局热键置顶；按住后重复 key-down 不重复切换。
- 实际窗口 WS_EX_TOPMOST 切换与取消。
- 状态窗口实际创建，WS_EX_NOACTIVATE，提示期间前台 HWND 保持为目标。
- 再次启动不创建第二后台实例，命令打开已有实例设置。
- 外部进程占用新快捷键时保存失败，磁盘仍保留旧组合；释放冲突后新组合保存生效。
- 提示/托盘开关、中文切换和 EXE 排除规则持久化。
- 被排除的测试进程通过真实热键操作仍被拒绝，设置显示排除结果。
- 真实设置快捷键打开设置；关闭设置不结束后台进程。
- CLI `--exit` 与真实退出快捷键均终止后台进程并撤销其添加的置顶。
- 重启后读取保存的快捷键并能操作窗口。
- 损坏配置自动打开恢复界面，原文件保持不变并生成 .bak。

配置目录使用系统临时目录下独立 QuietPin-integration-PID；测试退出清理自己的进程、窗口、热键与配置。产品不使用测试中的 AttachThreadInput 前台协调。

## 空闲资源测量

命令：`scripts/measure-idle.ps1 -Seconds 60`。使用最终 EXE（脚本记录 SHA-256 与上文一致），独立配置，托盘/提示关闭、Pin 未包含；启动稳定 2 秒后采样约 60.003 秒。

| 指标 | 本机实测 |
| --- | --- |
| CPU 时间增量 | 0.000000 秒（该采样分辨率内） |
| 单核等价平均 CPU | 0.00000%（该次采样内） |
| 初始 Private Bytes | 1,830,912 字节，约 1.75 MiB |
| 最终 Private Bytes | 1,728,512 字节，约 1.65 MiB |
| Working Set | 10,166,272 字节，约 9.70 MiB |
| 线程 | 1 |
| 句柄 | 135 |

Private Bytes 与 Working Set 是不同指标。CPU 增量为零只表示此观察窗口内没有可测 CPU 时间，不承诺所有机器、所有功能状态永久为零。本机数据不是跨平台基准，也未代替两小时稳定性测试。默认态源码没有常驻周期定时器；置顶确认、提示隐藏和退出清理时才短暂设置计时器。
